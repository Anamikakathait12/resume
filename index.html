Campus Lost & Found

An intelligent lost-and-found platform built for college campuses, combining a Flask REST API with a React frontend. The system automatically detects potential matches between lost and found items using a dual-signal engine: TF-IDF cosine similarity for text and OpenCV ORB feature matching for photos. It replaces manual scrolling through WhatsApp groups and notice boards with an automated, scored matching workflow.
